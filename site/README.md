# Lantean Code website

The Lantean Code organisation website, highlighting its open-source libraries, developer tools, and web applications.

Website: [lantean-code.github.io](https://lantean-code.github.io/)

## Contents

- `index.html` — page content, navigation, and social sharing metadata.
- `styles.css` — responsive layout and brand styling.
- `assets/` — website brand assets and social preview image.
- `.nojekyll` — serves the static files without Jekyll processing.

The website uses HTML and CSS with no build step or JavaScript dependencies. Rubik is loaded from Google Fonts with a system-font fallback.
