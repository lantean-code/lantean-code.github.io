# Lantean Code

Open-source .NET libraries, developer tools, and web applications.

This repository contains the Lantean Code organisation website, brand assets, and supporting resources.

## Repository structure

- `assets/` — brand marks, wordmark, avatar, design reference, and design previews.
- `site/` — static website source and the assets it uses.

## Branches

- `develop` contains the website source, full asset collection, and documentation.
- `main` contains the website at the repository root for GitHub Pages.

## Website

[lantean-code.github.io](https://lantean-code.github.io/)

The website uses static HTML and CSS, with no build step. Typography uses Rubik from Google Fonts with a system-font fallback.
